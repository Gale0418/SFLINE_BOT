# 四座寶庫的導引式學習

入口說「學習」，老人問：「你對這世界感到好奇嗎？」使用者選擇星海、地脈與生命、萬象法則、未來幻夢其中一條路線。四條路線互不綁定，各有四階段；每階段五段短講、五次理解題，再用五題複習挑戰確認本段內容，答對四題解鎖下一階段。

這是規則式教材導引，不是經實證校準的適性能力評量。挑戰重用本階段教過的題目並打亂題序，分數不代表整體能力，也不證明已能遷移到陌生情境。現有 1236 張知識卡與 300 題為內容來源；80 段導引教材仍是已選定內容的重新組織，不等於全部題目都被放進導引路線。

## 操作與資料位置

- `學習`：選寶庫；`繼續學習`：回到目前路線。
- `學習進度`／`學習地圖`：查看目前路線與已解鎖階段。
- `暫停學習`：保留教材位置和已解鎖階段；未完成挑戰下次重新開始。
- `刪除學習進度`：先確認，再清除目前路線；其他路線保留。
- 自由提問不受解鎖限制。切換一般「挑戰」會暫停導引，切回學習會退出一般試煉，避免 A–D 答案混用。

SQLite 檔案預設在**機器人伺服器**的 `data/private/learning.sqlite3`，可用 `LEARNING_PATH` 設定。LINE 手機端僅收發訊息與按鈕，不執行 SQL，也不會讀寫使用者手機資料。

資料庫存放 HMAC 化的使用者識別、所選路線、教材位置、挑戰狀態與最高分，不存原始 LINE user ID 或聊天全文。HMAC 是假名化，不是完全匿名；資料庫本身未加密，應以作業系統權限保護並妥善備份。更換 LINE channel secret 會改變識別結果，原有紀錄不會自動對應，需另行處理遷移。

所有進度更新在 SQLite 交易內完成。按鈕綁定使用者、路線與一次性狀態版本；舊按鈕、跨使用者按鈕、竄改及重複點擊不能跳關。切換路線會使之前顯示的按鈕失效，仍能用「繼續學習」取回教材。適用目前單機部署；容器或主機重建前必須保存資料卷，多主機部署需另設共享儲存。

## 人設與驗收界線

保持睿智、沉穩、耐心的老人：用解釋與證據表現智慧，不以自稱全知、責備答錯、強迫稱呼孩子或滿篇古語替代。老人可以坦承未知；科幻設定不因角色說得篤定就成為科學事實。短講和答案依據保留原始內容來源。

自動測試涵蓋四路線完整通關、補救重試、進度隔離、重新載入、刪除確認、過期按鈕、同時點擊，以及 LINE webhook 模擬。不等同於真實 LINE 帳號與線上模型的端到端驗證；部署更新後仍需實機走一次選路、追問、暫停與繼續。

2026-09-13 本機回歸結果：172 項測試通過，含分支整體覆蓋率 81.34%，導引模組約 95%。紀錄保存在 `results/guided-coverage.json`。這些是程式測試結果，不是模型準確率或學習成效。
