# 從星雲到宇宙網：天體尺度圖鑑

整理日期：2026-09-14。星雲不是一種天體的單一名稱，而是一群氣體與塵埃結構的歷史稱呼；有些孕育恆星，有些埋葬恆星。再把視野拉遠，恆星組成星團，星團與星際物質住在星系裡，星系又沿宇宙網聚集。

## 尺度旅程

```text
冷分子雲
  └─ 緻密核心／包克球 → 原恆星 → 星協或星團

恆星死亡
  ├─ 太陽類恆星 → 原行星狀星雲 → 行星狀星雲 → 白矮星
  └─ 大質量恆星 → 超新星遺跡 → 中子星／黑洞

星系
  └─ 星系群 → 星系團 → 超星系團／牆與纖維 → 宇宙網
```

## 星雲不是全都一樣

| 類型 | 能看見的原因 | 代表性重點 |
|---|---|---|
| 發射星雲／H II區 | 紫外光電離氣體，原子退激發光 | 常與年輕大質量星和恆星形成有關 |
| 反射星雲 | 塵埃散射附近星光 | 常偏藍，本身不靠電離發出主要光芒 |
| 暗星雲 | 塵埃遮住後方可見光 | 紅外與毫米波能看進較深處 |
| 分子雲 | 寒冷氣體以分子形態存在 | 恆星育嬰室，但不是整片同時坍縮 |
| 包克球 | 小型緻密暗雲 | 部分會形成一顆或少數恆星 |
| 行星狀星雲 | 老年恆星拋出的外層被核心照亮 | 與行星形成無關 |
| 超新星遺跡 | 爆炸噴出物與激波撞入星際介質 | 加熱氣體、散布元素、加速宇宙線 |
| 脈衝風星雲 | 中子星粒子風與磁場製造同步輻射 | 蟹狀星雲是代表案例 |

## 星團、星系與宇宙網

- **疏散星團：**較年輕、重力束縛較鬆，常在銀河盤，會逐漸散開。
- **球狀星團：**近球形、緻密且古老，常繞行星系暈，能保存早期星系歷史。
- **星協：**比星團更鬆散的同源恆星群，多數成員最後會漂散進銀河。
- **螺旋、橢圓、透鏡與不規則星系：**形態反映氣體、恆星軌道、恆星形成與合併歷史，但不能單靠外形還原所有過去。
- **宇宙網：**星系沿暗物質主導的纖維與牆聚集，交會處形成星系團，纖維間留下巨大空洞。
