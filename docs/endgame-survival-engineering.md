# 終局之戰：文明生存與異星戰爭工程學

整理日期：2026-09-14。對應知識卡 `sw810`～`sw845`。本章以《Muv-Luv》與其他科幻作品當提問入口，但不製作主觀勝率表；作品明示設定、工程推論與現實證據分開標示。

## 一、前哨站不是備份文明

火星上有人、有房子，不代表人類已經多一份文明備份。前哨站可以仰賴地球補給；真正的備份文明則要在地球長期失聯後，仍能讓下一代活下去、維修設備、製造關鍵零件、培養專業人才並延續制度。

判斷時應逐項公開，而不是只報一個「自給率」：

| 面向 | 可量化問題 | 常見盲點 |
|---|---|---|
| 物質閉環 | 水、氧、氮、食物與微量元素每年損失多少 | 水回收率高，不代表食物與濾材也閉環 |
| 能源 | 在地發電、儲能與黑啟動能力 | 有反應爐，不等於有燃料、冷卻與控制備件 |
| 製造 | 從原礦到合格零件能做到哪一層 | 會3D列印外殼，不等於會造晶片與藥品 |
| 人才 | 關鍵技能是否至少有多人且能跨代傳承 | 文件存在，不代表下一代實際修過 |
| 韌性 | 故障後能活多久、多久恢復、能否隔離 | 多台同型設備可能共享同一缺陷 |

NASA的生命維持與ISRU研究指出，降低地球補給可以靠提高回收、利用當地資源或兩者整合；但每種架構都有功率、質量、操作與技術共同性的代價。這正是為什麼「火星城市已自給」必須先說清楚系統邊界。

## 二、文明備份首先是依賴圖

把空氣、水、食物、電力、熱控、醫療、通訊和製造畫成依賴圖，再沿每條邊追查材料、設備、軟體、人員和上游能源，才能看見真正的單點故障。一顆看似不起眼的感測器、一種密封材或只有一位工程師知道的校準程序，都可能比巨大建築更關鍵。

同型備援能抵抗部分隨機故障，卻可能被相同設計錯誤、污染批次、韌體漏洞或共用電源一起擊穿。NASA把這類情況稱為共同原因失效；災難性功能可採不同硬體、軟體或物理原理的異質冗餘，但代價是介面與驗證更加複雜。

好的棲地還要能「優雅降級」：故障時先關閉娛樂、舒適與非必要實驗，隔離受損艙段，保住氣壓、氧氣、水、熱控和避難區。韌性不是永遠不壞，而是能偵測、承受、縮小功能並恢復。

## 三、多一顆行星，不代表故障已解耦

多座基地能避免火災、撞擊或局部疫情一次消滅所有人，但如果它們共用同一補給船、同一軟體、同一晶片產線或同一脆弱能源，仍會遭遇共同模式失效。大城市共享醫療、船塢與專家較有效率；小基地較容易隔離災害。合理架構是「可隔離、可互援、關鍵路徑不完全同源」。

把資料庫送上月球也不等於文明備份。資料仍需要能源、讀取設備、格式、語言、校驗、修復、教育與實作工具。種子工廠能逐步擴張採礦和製造，種子文明還必須包含生命維持、醫療、生殖、治理與文化傳承。

世代船的人口也沒有一個萬用神奇數字。任何門檻都依賴航程、事故率、年齡結構、生殖規則、遺傳庫、技能配置與社會穩定等假設。跨千年任務甚至可能先失去維修知識，再失去尚未完全故障的機器。

## 四、軌道優勢不是透視外掛

軌道平台適合廣域觀測、切斷地表交通和攻擊已定位目標，但厚岩層會遮蔽視線並吸收能量。對地下蜂巢而言，第一道問題是「在哪裡、長什麼形狀、哪些區域仍活躍」，而不是「砲有多大」。

地質雷達、電阻率、微重力與地震方法都依賴地下物性差異，並受深度、含水量、岩性與干擾限制。實務上需要多種感測交叉驗證，再用鑽孔或已知點校準。

即使看到異常，也要完成從偵測、定位、追蹤、分類、威脅判定、交戰授權到戰果確認的整條鏈。感測器覆蓋率不等於可攻擊率；若無法分辨敵人、誘餌與平民，更快武器只會更快放大錯誤。

## 五、軌道動能與雷射都不是免費魔法

從軌道投下重物仍要先把質量送上去，再提供離軌推進、姿態控制、終端導引與熱防護。高速再入會把動能轉成激波、熱與材料燒蝕；是否完整撞地取決於形狀、材料、角度、速度和大氣，不可只拿初始軌道速度換算爆炸當量。

雷射則受孔徑與繞射、指向追蹤、大氣吸收散射、雲與湍流、能源及廢熱限制。真空沒有空氣對流，連續射擊需要大型輻射器；在行星表面上空，天候和視線仍可能中斷光束。

昂貴平台面對蜂群時，還要比較同時可追蹤數、交戰通道、攔截彈庫、補充速度與交換成本。蜂群也需要能源、導航與製造，數量不會自動獲勝。短期會戰看現有戰力存量；長期戰爭更要看採礦、造船、維修和補損流量。

## 六、撿到外星神器，不代表科技樹瞬間全開

逆向工程要量測幾何、材料微結構、製程、容差、能源、控制和測試方法。即使裝置能啟動，文明也可能沒有製造它所需的純度、設備或供應鏈。

「插上線駭進母艦」還多了一層互通問題：雙方必須先有相容的物理介面、訊號編碼、封包語法、狀態機、語意與權限。能收到位元不代表知道位元的意思；對完全陌生系統，安全隔離、被動觀測和可重複實驗比直接執行未知命令合理。

未知外星樣本也要先封存。NASA的行星保護同時防止地球生命污染其他世界，也要求對可能有生物風險的返回樣本維持受控與驗證。這不是宣稱外星病原必然存在，而是避免一次不可逆錯誤毀掉環境與科學證據。

## 七、蜂群的弱點取決於控制架構

摧毀母腦是否讓全軍停擺，要先知道系統是否中央化。若個體擁有本地任務、能分享觀測、重選協調者並重新規劃，單一節點失效只會降低效率。若節點提供不可替代的能源、同步或身分授權，斬首才可能有效。

會再生或適應也不等於無敵。修復必須消耗物質、能量、時間與控制資訊；只要損傷率超過補給、代謝或製造率，系統仍會失效。真實演化發生在族群與世代，個體瞬間獲得完美抗性需要作品另行定義機制與代價。

《Muv-Luv》的BETA因官方故事所述的長期外星戰爭，很適合被抽象成「地下、分工、持續補損的異星威脅」來研究感測、物流和指揮架構；沒有官方量測資料的細節則不假裝是真實生物學。

## 八、跨作品終局戰應該怎麼比較

先固定作品、版本、時間點與場景，再把證據分成官方明示數值、可重複事件、角色宣稱和玩家平衡機制。最後建立威脅矩陣：

| 維度 | 要問的問題 |
|---|---|
| 尺度 | 單艦、行星、恆星系或銀河？ |
| 機動 | 亞光速、固定航道、星門或自由跳躍？ |
| 補損 | 多久能製造、修復或繁殖下一批？ |
| 感測 | 多遠能偵測、分類、追蹤與抗欺騙？ |
| 指揮 | 中央節點、階層式，還是分散自治？ |
| 資源 | 能源、原料、彈藥與交通依賴什麼？ |
| 攻擊終態 | 毀城、滅絕地表、吹走大氣，還是打散行星？ |
| 停止條件 | 殺死首領、摧毀工廠、切斷航網，還是必須逐個清除？ |

這張表不會算出假裝精準的「87%勝率」，但能指出答案到底卡在哪個假設。尤其「行星級」必須再問破壞機制、時間與終態；燒毀地表和克服行星引力束縛能不是同一件事。

## 九、《Muv-Luv》與《Girls Garden》的科學邊界

- 《Muv-Luv Alternative》官方設定確認平行世界與BETA戰爭；它們是故事前提，不是現實實驗結果。
- 《Muv-Luv Girls Garden》官方稱MG為巨大人型機械；要判斷現實可行性仍需尺寸、質量、材料、功率、關節負載、地面承壓與跌倒工況。
- 《The Day After》的永久重力異常是作品內災變。旋轉棲地或加速飛船只能產生局部等效重量，不能留下全球重力場改寫。
- Everett相對態／多世界是量子力學的詮釋研究，不提供可穿越分支的引擎、入口或通訊協定。

## 主要來源

- NASA：Moon to Mars Architecture、生命維持與ISRU、載人系統共同原因失效、分散式太空船自治、再入氣動熱、雷射通訊與行星保護。
- USGS：地下空洞的地質雷達、電阻率、重力與地震偵測。
- NIST：供應鏈韌性、資訊互通、先進製造量測與資格驗證。
- American Physical Society：Everett相對態與多世界相關文獻。
- Muv-Luv Portal、Muv-Luv Girls Garden：作品官方故事與機體定位。
