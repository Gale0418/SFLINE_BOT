- [ ] Flask 監聽 Port：`__________`；ngrok 轉送 Port：`__________`。
- [ ] 以本機請求測試健康檢查或 Webhook 路徑：`__________`。
- [ ] 確認該 Port 沒有被其他程式占用或服務已停止。

### E2. 確認 ngrok

- [ ] ngrok 指令使用正確 Port：`ngrok http __________`。
- [ ] ngrok 終端機仍在執行，沒有退出或顯示錯誤。
- [ ] 使用目前有效的 HTTPS Forwarding URL，而非過期網址。
- [ ] 確認 LINE Webhook URL 已同步更新。
- [ ] 確認沒有把 `https://` 公開網址誤當成本機 Flask 監聽目標。

### E3. 依錯誤位置判斷

- [ ] 本機請求也失敗：先修正 Flask 啟動、Port 或路由。
- [ ] 本機成功、ngrok 失敗：檢查 ngrok 目標、隧道狀態與防火牆。
- [ ] ngrok 成功、LINE 驗證失敗：檢查 Webhook URL、路徑、簽章驗證與回應狀態碼。
- [ ] 僅 API 回答失敗：檢查 API 金鑰、模型設定、配額、逾時與錯誤日誌。
