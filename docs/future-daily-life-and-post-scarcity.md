# 未來日常生活與後稀缺文明：先改房間、衣服，還是人類？

整理日期：2026-09-14。本冊從《哆啦A夢》式未來道具出發，但不替不存在的產品預言上市年份。每個問題都分成作品功能、現有原型、工程斷層與社會後果。

## 1. 空氣調節球：真正難的是邊界與散熱

現實已有手腕熱電裝置、降溫背心、座椅送風、局部輻射冷卻和個人舒適系統。它們能讓特定部位感覺較舒適，卻不等於在戶外維持一顆隱形冷暖氣泡。

- 空氣會被風、浮力和人體移動快速混合；沒有牆就要不斷補充處理過的空氣。
- 冷氣不是消滅熱，而是把熱搬走；冷端越小巧，熱端、電池和散熱往往越棘手。
- 局部空調只有在中央空調跟著放寬設定或縮小服務區域時，才可能帶來整體節能。
- 濕度、風速、輻射溫度、衣著與活動量都影響體感；只控制氣溫不夠。

因此近期合理路線不是「等某一年突然出現神奇球」，而是建築、智慧衣與個人裝置分層合作。

## 2. 第二層皮膚：從舒適跨到生命維持

智慧衣可整合保溫、透濕、風扇、液冷、相變材料、感測與主動控制。環境越極端，它就越不像衣服，越像一艘穿在身上的小太空船。

| 環境 | 不能只解決的單一問題 | 完整系統還需要 |
|---|---|---|
| 炎熱潮濕 | 降低皮膚溫度 | 排熱、排汗、補水、續航 |
| 深海 | 從水取氧 | 排二氧化碳、抗壓、保溫、減壓程序 |
| 真空 | 提供氧氣 | 壓力、二氧化碳移除、熱控、微流星體防護 |
| 深空 | 修復部分DNA傷害 | 材料屏蔽、監測、避難與任務規劃 |
| 微重力 | 適應漂浮 | 骨骼肌肉、平衡、心血管與返航重力再適應 |

光遺傳學也不是「適應燈」：它要先使特定細胞表達感光蛋白，再以特定光控制，且仍有載體、免疫、穿透與長期安全問題。

## 3. 自動尋星：可能宜居不等於可以搬家

宜居帶只表示在一定大氣假設下可能有表面液態水。自動探測器與AI可排序候選星球，但資料仍可能缺少表面、雲層、大氣和生物訊號的唯一解釋。

一艘真正的星際逃生艙還要解決：長期能源、導航與減速、封閉生態、修復、醫療、生殖、輻射、治理、行星保護及多個備選目的地。能抵達是一項任務；能建立可長期維持的社會是另一項任務。

## 4. 任意門與時光機：先追問它改掉了哪種成本

- 任意門會壓低距離成本，但入口、容量、土地、目的地權限與安全仍可能稀缺。
- 瞬間交通會迫使邊境、檢疫、物流、救災與位置隱私重新設計。
- 相對論時間膨脹可讓旅行者比留守者少經歷時間；回到自己的過去則仍缺乏可建造、可控制的機制。
- 「未來人送回設計圖」會產生資訊沒有原始作者的自舉悖論。
- 直接改寫世界規則的電話亭比較像宇宙管理員介面，適合做思想實驗，不適合排發明時間表。

## 5. 後稀缺：消除的是被迫勞動，不是人的主體性

如果自動化供應基本生活，人仍可照護、學習、遊戲、研究、創作與參與公共決策。自我決定理論提醒我們，自主、勝任與關係連結會支持較高品質的動機；這不保證人人自動振作，也不能忽略教育、資源和心理健康差異。

理想自動化不是把人從所有活動中刪除，而是減少危險、重複與生存所迫的工作，保留選擇、覆寫、學習、承擔與互相需要的空間。無聊可能提示目前活動缺乏投入或意義，卻不會自動把每個人變成藝術家。

## 6. 導引式聊天路線

開場：「如果有一顆球能讓你永遠舒適，你想先改造房間、衣服，還是自己的身體？」

1. **舒適工程**：局部空調 → 熱搬運 → 濕度與露點 → 智慧衣。
2. **極端適應**：人工鰓 → 深海壓力 → 真空 → 輻射與微重力。
3. **星際搬家**：宜居帶 → 自動尋星 → 抵達與殖民 → 星際逃生艙。
4. **文明衝擊**：任意門 → 檢疫與隱私 → 時光機 → 因果悖論。
5. **生活意義**：自動化 → 工作與活動 → 三種心理需求 → 後稀缺人生。

最後的挑戰不是猜年份，而是逐項回答：熱或物質去哪裡、能量從哪裡來、失效時怎麼活、誰有控制權、普及後哪種成本會轉移到別處？
