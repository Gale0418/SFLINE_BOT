# 後人類飛昇與人體 Root：升級前先看誰能關機

整理日期：2026-09-14。本冊把超級士兵、吸血鬼上位種、High Human、奈米血液、義體與腦機介面放在同一張風險圖上。作品設定用來提出問題；現實能力以監管機關、臨床資料與研究文獻為準。

## 飛昇不是單一科技

| 路線 | 現實最接近的技術 | 科幻跳躍 |
|---|---|---|
| 生物強化 | 基因／細胞治療、藥物、再生醫學 | 一針永久提升全身所有能力 |
| 機械強化 | 義肢、人工耳蝸、神經刺激器 | 全身義體同時超越人類且零維修 |
| 神經強化 | 腦機介面讀取有限運動或語言訊號 | 完整讀寫思想、下載技能與遠端駕駛人格 |
| 奈米強化 | 奈米載體、實驗性微／奈米機器 | 血中自治機器瞬間重建全身並自我複製 |
| 數位飛昇 | 神經資料、AI模型、有限腦模擬 | 複製完整意識並證明原人格連續 |
| 種族轉化 | 無直接現實對應 | 人類轉成永生上位種並保留所有優點 |

## 作品中的「上位種族病」

如果轉化同時提供長壽、力量、速度、疾病抗性、美貌與特殊能力，又不失去關係、生育、自主或身份，選擇便不再是道德難題，而只是延遲領取升級包。

較完整的世界觀可以把飛昇設計成側向選擇：

- 強度提高，但能量、散熱或維修成本上升；
- 壽命延長，但生育、適應速度或跨世代關係改變；
- 感官擴張，但資訊過載與隱私風險增加；
- 身體可替換，但供應鏈、相容性與控制權成為新弱點；
- 群體同步提高合作，卻可能犧牲拒絕、沉默與私人記憶。

## 現實科技到哪裡了

FDA 已核准多種細胞與基因治療產品，但用途集中在特定疾病，不是健康人的全能力強化。植入式腦機介面研究主要瞄準失去運動或溝通能力者，仍需要評估安全、軟體、材料、居家功能與長期成效。

微／奈米機器研究正探索標靶藥物、腫瘤穿透與外部場驅動；從實驗裝置跨到全身自治維修，還有製造、生物相容、毒性、定位、能源、清除與臨床驗證等巨大斷層。

「部分表觀遺傳重編程」在動物與細胞研究中是活躍方向，但不能把恢復部分標記或功能直接翻譯成整個人變年輕；細胞身分、腫瘤與遞送控制仍是核心風險。本冊不採用沒有可核對試驗登錄的「全球第一針」宣稱。

## 人體 Root 權限驗收表

1. **控制**：誰能讀取、寫入、停用或改變裝置？
2. **連線**：沒有網路、雲端或公司時，基本生命功能是否仍可運作？
3. **更新**：安全修補如何驗證，使用者能否延後、回復或拒絕非必要變更？
4. **資料**：神經、生理與記憶衍生資料由誰保存、移轉與刪除？
5. **退出**：能否取出、停用或換廠商？退出會不會失去身體功能？
6. **故障**：有沒有安全降級、實體控制、醫療救援與責任歸屬？
7. **後代**：變更是否可遺傳？尚未出生者如何承擔不可逆風險？
8. **公平**：不升級的人會不會失去工作、保險、公民權或競爭資格？

## 導引式聊天路線

開場可問：「如果有一種升級能讓你更強、更久壽，但製造商保留更新權，你會接受嗎？」接著依答案進入生物、義體、神經、奈米或數位路線。每次升級都必須回答能力、代價、控制者、可逆性與證據等級，最後再做角色互換：如果被迫升級的是士兵、員工、孩子或下一代，原答案是否仍成立？
