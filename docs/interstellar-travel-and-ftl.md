# 星際旅行與超光速科技

整理日期：2026-09-14。這份資料把「已飛過」「可由已知物理推演」「有數學模型但沒有工程路徑」與「純作品設定」分開。**目前沒有任何人造物體或資訊被證實能在局部空間超越真空光速。**

## 先看真正的距離

比鄰星距離約4.24光年。下表是假設瞬間到達巡航速度、全程等速且不減速的尺度比較，不是任務計畫：

| 巡航速度 | 地球參考系單程時間 | 船上固有時間 | 代表意義 |
|---:|---:|---:|---|
| Voyager 1量級，約0.000057c | 約74500年 | 幾乎相同 | 現代探測器尺度 |
| 0.001c | 4240年 | 幾乎相同 | 仍需跨文明保存 |
| 0.01c | 424年 | 約424年 | 世代船尺度 |
| 0.1c | 42.4年 | 約42.2年 | 高速星際工程門檻 |
| 0.2c | 21.2年 | 約20.8年 | Starshot克級光帆目標量級 |
| 0.5c | 8.48年 | 約7.34年 | 相對論差異開始明顯 |
| 0.9c | 4.71年 | 約2.05年 | 能量、塵埃與輻射極端化 |
| 0.99c | 4.28年 | 約0.60年 | 船員時間短，不代表地球不用等 |

收到探測資料還要再等約4.24年光行時間。完整任務必須加入加速、減速、導航與目的地運作。

## 不超光速的推進方法

| 方法 | 現況 | 優點 | 致命瓶頸 |
|---|---|---|---|
| 化學火箭 | 已廣泛使用 | 高推力、適合起飛 | 排氣速度不足以支撐星際巡航 |
| 離子／霍爾推進 | 已在太空使用 | 高效率、可長時間推進 | 推力小、受電源與壽命限制 |
| 核熱推進 | 地面研究與開發 | 比化學火箭高效率且保有推力 | 反應爐、氫儲存、材料與發射安全 |
| 核電推進 | 概念與元件成熟度不一 | 深空仍可供電給電推進器 | 功率質量比與巨大散熱器 |
| 太陽帆 | 已完成實際飛行示範 | 不攜帶推進劑 | 遠離太陽後光壓快速變弱 |
| 雷射光帆 | 系統研究 | 能源留在出發地，可推克級探測器至約0.2c | 雷射陣列、帆耐熱、瞄準、塵埃、通訊與煞車 |
| 核融合推進 | 遠期概念 | 高比衝與潛在較高推力 | 尚無適合飛船的高增益長期融合系統 |
| 核脈衝推進 | 歷史概念研究 | 已知核物理下可得巨大推力 | 核爆安全、輻射、推板壽命、條約與政治 |
| 反物質推進 | 粒子反應已知，引擎未實現 | 已知反應中極高能量密度 | 製造、儲存、準直、廢熱與輻射 |
| Bussard衝壓引擎 | 理論概念 | 想沿途收集星際氫 | 介質太稀、融合太難且收集會造成阻力 |

## 星際飛船不是只有引擎

1. 高速塵埃：在0.1c以上，即使微小塵粒也可能像高能爆炸物；需要多層犧牲盾、磁場與前方偵測。
2. 減速：飛到目的地但停不下來只是一瞬間掠過。磁帆、電帆、目的地星光或攜帶燃料都會增加任務難度。
3. 通訊：訊號最多以光速返回，發射功率與接收口徑還要對抗距離平方造成的微弱訊號。
4. 載人生命：世代船要維持幾百年生態與社會；電影式冷凍睡眠尚不存在，短期醫療低溫也不能直接外推成數十年復甦。
5. 可靠性：目的地沒有維修站，軟硬體、能源、材料與生態都要能自我診斷、替換甚至製造。

## 為什麼光速不是一面普通的牆

有靜止質量的飛船由低於光速加速時，速度越接近 `c`，所需能量增加得越劇烈，不能靠「再踩一點油門」跨過去。光速也是局部訊息與因果關係的上限；若可控訊息能任意超光速，不同慣性參考系可能對發送與接收次序產生衝突，進而構成把訊息送回自身過去的因果迴圈。

宇宙膨脹讓非常遙遠星系的距離增加率可超過光速，不是星系在自己的局部空間中闖過光障。影子、光點掃過遠方表面的表觀速度也可大於光速，但沒有單一物體或可控訊息沿著那條路徑超光速移動。

## 超光速方案的科學分級

### Alcubierre曲速泡

數學想法是讓飛船附近局部保持低於光速，由前方時空收縮、後方時空膨脹搬運整個區域。原始超光速解需要違反通常能量條件的負能量分布；此外還有視界、曲速泡建立與控制、量子不等式、高能粒子累積和因果問題。後來的正能量研究多半只得到**亞光速**曲速度規，不能改寫成「曲速引擎已被證明可行」。

### 可穿越蟲洞

蟲洞不是在普通空間跑得更快，而是假設兩地之間存在較短時空路徑。Morris–Thorne類模型需讓洞喉無事件視界並以特殊應力能量保持開放；人類沒有發現、製造或穩定宏觀可穿越蟲洞。可移動洞口還可能導致時間機器式因果問題。

### 快子

快子是假想中永遠位於超光速區域的粒子，不是普通物質加速跨越光速後的形態。量子場論裡的「tachyonic」常代表某個狀態不穩定，不能直接解讀成發現超光速粒子；目前也沒有可靠觀測。

### 量子糾纏

糾纏產生非古典相關性，但單方測量結果不可控制。雙方要確認相關性仍需普通古典通道，因此量子傳態、量子金鑰與糾纏都不能提供超光速星際電話。

### 超空間、跳躍引擎與星門

這些都是很好的世界觀工具，但目前沒有實驗證據。想讓作品內部自洽，可以明訂：

- 航道是否只能沿固定節點；
- 建造出口是否必須先用亞光速飛船抵達；
- 質量與距離如何決定能源；
- 是否存在冷卻或重新充能時間；
- FTL通訊能否存在，以及如何防止因果悖論；
- 跳躍失準、重力井與導航錯誤的代價。

限制越明確，超光速科技越不像任意傳送的劇情橡皮擦。

## 適合報告的一句總結

星際旅行不必先發明超光速：雷射光帆、融合推進與世代船都能在已知物理下討論，只是代價大得驚人。真正的FTL方案目前不是「缺幾個零件」，而是尚未證明自然界提供所需的時空、能量與因果條件。
