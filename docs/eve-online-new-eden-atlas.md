# 《EVE Online》New Eden世界觀導覽

整理日期：2026-09-14。對應知識卡 `sw687`～`sw714`。本章所有作品設定優先引用CCP的EVE Universe；現實科學比較不把lore術語當成實驗證據。

## 一、失去故鄉的人類星團

New Eden是《EVE Online》的人類文明舞台。遠古殖民者被認為經由EVE Gate抵達，通道崩潰後，殖民地失去支援網路並經歷漫長黑暗時代。這個背景讓每個文明都同時是人類後代與失落歷史的重新發明者。

## 二、三層旅行與一層通訊

| 系統 | 作品中的用途 | 現實邊界 |
|---|---|---|
| Warp drive | 同一恆星系內超光速移動 | depleted vacuum描述未經現實實驗證實 |
| Stargate | 以成對人工蟲洞連接星系 | 尚無宏觀可通行蟲洞工程 |
| Wormhole／Anoikis | 不固定的未知航路與孤立空間 | 理論蟲洞不等於已觀測航道 |
| Fluid router | 跨光年通訊、交易與治理 | 量子糾纏不能傳遞超光速可控訊息 |

## 三、死亡變成資訊工程

Capsuleer透過hydrostatic capsule直接控制船艦。膠囊毀壞時，transneural burning scanner破壞性記錄腦狀態並傳到新複製體，使駕駛成為有效不死的infomorph。

這並非無條件永生：掃描、傳輸、複製體與設施都可能失敗，也留下「記憶相同的副本是否就是本人」的哲學問題。Warclone使用不同人格傳輸架構，距離、備份與複本風險不能和capsuleer混為一談。

## 四、玩家看不見的船員

Capsuleer集中了導航與戰鬥指揮，並不表示每艘船只有一人。官方lore明確保留工程、維修和補給船員；部分小型frigate才可能高度自動化到單人操作。大型船爆炸因此不只是可重生駕駛損失一個道具，也可能是大量普通人的死亡。

採礦、精煉、藍圖、製造、物流、交易和戰爭則形成虛擬工業循環。它適合用來理解供應鏈與毀損如何創造需求，但仍受遊戲開發者設定的資源生成與經濟規則控制。

## 五、四大帝國不是四色性格測驗

| 勢力 | 核心制度 | 不能忽略的矛盾 |
|---|---|---|
| Amarr Empire | 神權君主、貴族與官僚帝國 | 信仰、征服與奴役 |
| Caldari State | 巨型企業分治的企業國家 | 公司福利與公司支配相連 |
| Gallente Federation | 多元聯邦民主 | 自由理想、干預與內部分歧 |
| Minmatar Republic | 部族與共和機構並存 | 離散族群、創傷與多重身分 |

CONCORD是帝國間協調、執法和貿易監督的超國家機構，不是統一政府。高安全區的制裁是犯罪後果，不是保證犯罪不會發生。

## 六、文明走向的極端實驗

- Sansha's Nation：以烏托邦效率為名消除個體意志。
- Jove Empire：基因與軍事科技極度先進，仍被疾病、人口和社會脆弱性侵蝕。
- Triglavian Collective：長期受Abyssal Deadspace塑造，發展時空與bioadaptive科技。
- Rogue Drones：會採礦、製造、變異與分巢的野生機器生態。
- Sleeper Drones：失落文明留下的高階自主防衛系統。
- Drifters：使用Sleeper技術、關係密切但起源與目的仍未完全揭露的勢力。
