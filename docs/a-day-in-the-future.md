# 未來人的一天：從智慧晨光到夢境劇場

整理日期：2026-09-14。本冊不假設所有技術在同一年、同一城市或每個家庭同時普及，而是用一天的時間軸比較已存在的原型、正在發展的系統與仍屬科幻的跳躍。

## 07:00｜房間先醒來

窗邊照明逐漸模擬晨光，床墊用動作與呼吸趨勢選擇較不突兀的喚醒時點。住宅的本機控制器已先調整照明、溫度與通風，但使用者仍能關閉感測或改用普通開關。

智慧床只能提供趨勢，不是睡一晚就完成全身診斷。浴廁感測器也許能長期觀察排泄物指標，但必須先解決家庭成員辨識、污染、假警報與極私密資料的使用權。

## 08:00｜衣服、早餐與循環住宅

智慧衣依環境提供局部加熱、通風或健康感測，沒有電時仍是一件安全可穿的衣服。防污與抗菌材料可減少洗滌，卻不代表汗、皮脂和所有病原體會自動消失。

AI根據飲食偏好與健康資料建議早餐；食物列印機負責形狀與份量，培養肉與垂直農場提供部分原料。這些系統仍需要農業、能源、清潔與物流，不是從資料檔案憑空生成料理。

住宅把太陽能、電池、熱泵和可控負載組成小型能源系統，也回收灰水與部分廢水。國際太空站已示範高比例水回收，但現實家庭還要面對維護、污染物與濃縮廢料；循環越完整，管理越不能消失。

## 09:00｜移動，或讓工作來到眼前

自動駕駛車只在自己的設計範圍內可靠。空中計程車即使通過航空認證，仍受噪音、天候、起降點與空域容量限制；真空管列車也不能只看最高速度，還要計算車站減速、逃生和全線維護。

許多資訊工作改用空間音訊、共享模型與遠距機器人，減少通勤與出差，但照護、材料操作和關係建立不會全部被傳送成影像。

## 10:00｜AI老師帶路，但不替學生長出能力

每位學生可有AI助教調整練習、提示與解釋方式。教師負責課程目標、錯誤覆核、社群與倫理；學生也要學會查證，而不是把流暢答案當真理。

虛擬實驗室讓人反覆練習危險或昂貴情境，真實實驗則暴露材料誤差、儀器故障和模型外現象。技能仍需要感覺、動作與情境練習，不能像電影檔案般瞬間下載進腦中。

## 13:00｜AI同事與人類責任

AI整理資料、尋找模式並產生選項；人類設定目標、處理例外、驗證證據並承擔決策後果。任務風險越高，所需的監督、紀錄與權限越嚴格。

自動排班與績效系統可以一致，也可能一致地傷害所有被資料忽略的人。未來工作是否公平，取決於員工能否理解、更正、申訴與參與設計，不取決於報表有幾位小數。

## 18:00｜家裡成為診間的一部分

穿戴裝置與家庭感測器觀察長期趨勢，健康數位孿生模擬有限問題，遠距醫護確認重要異常。系統必須顯示不確定性，不能把錯誤量測直接送去配藥。

生物列印正協助組織模型與再生醫學研究，但完整替換器官還需要血管、神經、免疫相容和長期臨床驗證。健康壽命研究也不等於已能讓每個人永遠二十歲。

## 20:00｜未來的陪伴與娛樂

立體顯示與AR讓遠方親友像出現在同一空間，AI朋友提供對話與提醒；兩者都能補充關係，卻不能自動取代彼此承擔、共同經歷與真人照護。

全沉浸VR仍缺少完整觸覺、平衡、溫度、嗅味與安全神經介面。睡前的聲音或意圖也許能影響部分夢境，卻不能像串流平台般精準播放整晚故事。

## 一天結束後的五個驗收問題

1. 沒網路、沒訂閱或公司倒閉時，基本功能還在嗎？
2. 系統錯了，使用者能看懂、停止、覆寫和申訴嗎？
3. 省下的時間、能源與勞動，有沒有在別處產生新成本？
4. 私密資料真的需要離開家中嗎？誰能刪除與移轉？
5. 它是在擴充人的選擇，還是讓人逐漸失去能力與控制？

## 導引式聊天路線

開場：「如果明天醒來，你的家已經比你更早知道今天需要什麼，你會覺得貼心，還是可怕？」

依序解鎖：智慧早晨 → 衣食與循環住宅 → 未來交通 → AI教育 → 人機工作 → 家庭醫療 → 未來社交娛樂。最後讓學習者設計自己的未來一天，並替每項科技填上能源、資料、失效、責任與退出方式。
