## 五個必演場景

### 1. Help 與人格

- [ ] 傳送「幫助」。
- [ ] 回覆能說清楚問答、科學邊界、試煉、分數與退出。
- [ ] Quick Reply 可開啟挑戰或普通問題。
- [ ] 語氣像耐心長輩，沒有每句重複稱呼「孩子」。

### 2. 完整五題試煉

- [ ] 傳送「挑戰」。
- [ ] 選一座寶庫與難度。
- [ ] 混用按鈕與直接輸入 A／B／C／D 完成五題。
- [ ] 每題有正誤、正解、解說、來源與下一題。
- [ ] 最後有總分、最高連勝、稱號，並自然恢復長輩語氣。

### 3. 答錯與退出

- [ ] 故意答錯一題，確認沒有羞辱字眼。
- [ ] 傳送「分數」，確認進度正確。
- [ ] 傳送「退出」，確認舊題按鈕不能繼續計分。

### 4. 離線核心

- [ ] 暫時讓 OpenAI 回覆失敗。
- [ ] 「幫助」「挑戰」「試煉規則」仍可使用。
- [ ] 試煉五題仍可完成。
- [ ] 普通問答顯示安全的宇宙訊號備援文字，不出現 stack trace。

### 5. 連續與邊界操作

- [ ] 快速連按兩個答案，確認同一使用者依序處理、不跳題或重複計分。
- [ ] 在試煉中輸入普通問題，確認 Bot 先要求完成或退出當前試煉。
- [ ] 重按上一題的按鈕，確認被拒絕。
- [ ] 等場次逾時或重新啟動服務後按舊按鈕，確認顯示場次失效。
