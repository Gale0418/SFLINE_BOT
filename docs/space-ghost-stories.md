# 星海怪談：十五則會自己解釋的宇宙鬼故事

整理日期：2026-09-14。這不是把靈異事件當科學，而是用怪談引起問題，再把故事拆成觀察、假說、驗證和仍未知的部分。

> 「孩子，星海裡沒有風。倘若艙外有人敲門，先看壓力計，再決定要不要害怕。」

## 怪談與科學揭曉

| 怪談 | 優先檢查 | 不能亂下的結論 |
|---|---|---|
| 艙外有人敲門 | 熱脹冷縮、泵浦、閥門、姿態控制與撞擊 | 未知聲響不等於鬼 |
| 閉眼仍看見閃光 | 高能粒子與太空輻射 | 不是窗外有人打燈 |
| 無線電傳來心跳 | 脈衝星週期訊號 | 規律不等於智慧生命 |
| 收到自己的求救聲 | 中繼、重送、錄音與時間戳 | 訊號不會無代價穿越時間 |
| 系統多出一名船員 | 感測融合、重複ID、測試帳號、快取 | AI輸出不等於世界真相 |
| 白色物體一路跟船 | 冰晶、隔熱片、排氣顆粒 | 單眼影像無法直接判距 |
| 星星突然消失 | 遮光、污染、姿態、曝光、暗雲 | 普通暗星雲不會瞬間關掉全波段天空 |
| 遠方恆星其實已死 | 光行時 | 不能說夜空大多數星星都已死亡 |
| 返航時故人全逝 | 相對論時間膨脹 | 不能因此回到過去 |
| 全員做同一個夢 | 睡眠、壓力、CO₂、共同暗示 | 相似敘述不是心靈感應證明 |
| 廢船仍祝船員生日 | 排程、舊資料與殘存電源 | 自動播放不證明機器有靈魂 |
| 看見另一艘自己 | 重力透鏡多重影像 | 附近飛船任意複製極不可能 |
| 沒有日出的世界 | 流浪行星 | 黑暗不代表沒有內部熱或地下環境 |
| 真空傳來尖叫 | 無線電、結構振動、資料聲化 | 真空本身不能傳一般空氣聲波 |
| 全宇宙都不回答 | 搜尋不足、生命稀有或訊號難認 | 黑暗森林不是已證實宇宙定律 |

## LINE機器人的互動形式

1. 老人用兩到三句講出怪談開場。
2. 使用者選擇「物理現象、設備故障、心理因素、未知」。
3. 老人依序公布可觀察證據與最佳解釋。
4. 最後明列科學能解釋到哪裡，不用一句「都是幻覺」草率收尾。

> 「那敲擊每隔十七秒出現一次。工程師關閉冷卻閥後，聲音仍多響了一次。」

最後一下可以保留作故事餘韻，但知識解說不能把它宣稱為超自然證據。
