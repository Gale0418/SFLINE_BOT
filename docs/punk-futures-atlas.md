# Punk未來圖鑑：每種未來在反抗什麼？

整理日期：2026-09-14。`-punk` 類型沒有統一官方名冊，名稱會重疊、演變，也可能只是社群使用的美術標籤。本冊用「核心科技、社會矛盾、證據邊界」整理，不把文學類型當工程預測。

## 先判斷它是不是真的有 punk

Cyberpunk 的典型張力是「高科技、低生活」：資訊、義體與網路很先進，權力卻集中在企業、國家或平台。後續類型常借用 `punk` 後綴；有些保留反權力核心，有些主要是復古未來的視覺語彙。

判讀一個世界時可問：

1. 誰掌握關鍵能源、資料、身體或維修權？
2. 一般人如何挪用、修理或反抗技術？
3. 作品是在批判制度，還是只把齒輪與霓虹貼在表面？
4. 那套技術符合哪個年代的想像，又漏掉哪些污染、勞動與供應鏈？

## 常見類型

| 類型 | 核心語彙 | 常見問題 |
|---|---|---|
| Cyberpunk | 網路、義體、AI、巨型企業 | 資料與身體由誰所有 |
| Postcyberpunk | 技術已日常化、主角可能在體制內 | 能否修補而非只逃亡 |
| Steampunk | 十九世紀、蒸汽、齒輪、架空工業 | 帝國、階級與煤煙是否被浪漫化 |
| Dieselpunk | 兩次大戰間、柴油、量產、航空與裝甲 | 總體戰、宣傳、石油權力 |
| Atompunk | 原子時代、冷戰、太空競賽 | 核能樂觀與核毀滅並存 |
| Clockpunk | 前工業精密機械、發條與自動機 | 沒有電子控制能做到多少 |
| Teslapunk | 電氣奇觀、線圈與無線能源幻想 | 真實電磁學與神話化發明家 |
| Biopunk | 基因、合成生物、身體改造 | 專利、優生、疾病與同意 |
| Nanopunk | 分子製造、奈米機器 | 控制、驗證、污染與失控複製 |
| Solarpunk | 再生能源、生態修復、社區自治 | 公平轉型而非綠色布景 |
| Hopepunk | 困境中的照護、團結與主動希望 | 希望是不是需要付出與組織 |
| Lunarpunk | 夜色、生態、地方知識與靈性 | 被效率敘事忽略的知識與群體 |
| Silkpunk | 有機材料、手工技術、東亞／太平洋靈感 | 技術想像是否只能來自西方工業史 |
| Cassette futurism | 類比介面、磁帶、厚重終端 | 人機介面、維修與有限連線 |
| Raypunk／Raygun Gothic | 火箭、射線槍、流線太空時代 | 太空樂觀與物理不可能的距離 |
| Stonepunk | 石器材料加上誇張工程 | 材料、能量與加工精度限制 |
| Mythpunk | 重寫神話與民間故事 | 誰有權定義正統敘事 |

## 三個常見誤區

- **不是能源名稱就足夠**：太陽能城市如果權力、土地和收益仍高度集中，不會自動成為 solarpunk。
- **不是舊科技真的比較乾淨**：蒸汽機只是能量轉換設備，歷史工業體系仍高度依賴燃煤、礦業與勞動。
- **不是每個標籤都有穩定定義**：越新的網路用語越應標示「社群慣用」而非假裝學界已有共識。

## 混種世界比純分類更有趣

類型可以交叉：太空殖民地可能具有 cassette-futurist 的介面、biopunk 的生命維持、solarpunk 的循環生態和 cyberpunk 的資料壟斷。分類的用途是找出世界的技術與權力邏輯，不是警察式判定作品只能待在一格。
