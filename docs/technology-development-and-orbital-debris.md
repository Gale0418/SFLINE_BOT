# 從遙感五十號02星到科技樹：軌道碎片與技術發展

整理日期：2026-09-19。對應知識卡 `sw880`～`sw930`。本章把一宗仍在調查的衛星碎片事件當作入口，示範如何從觀測證據、工程限制與技術成熟度建立可信的科技樹。事件已確認部分、合理推論與科幻設定必須分開。

## 一、先確認事件，不替未知原因寫劇本

中國國家航天局公告顯示，遙感五十號02星於2026年3月15日由長征六號改火箭發射並進入預定軌道。到了9月4日，公開軌道資料中已出現至少43個名稱為 `YAOGAN-50 02 DEB` 的編目物體；這能支持「與該任務關聯的碎片群已被追蹤」，卻不能單靠名稱證明整顆衛星完全毀滅、碎裂發生在9月4日，或事故一定由爆炸造成。

讀這類消息要拆成四層：

| 層級 | 可以說什麼 | 不可以偷渡什麼 |
|---|---|---|
| 官方發射公告 | 發射時間、火箭、宣稱用途、入軌成功 | 載荷細節與後續健康狀態 |
| 軌道目錄 | 物體名稱、編號、軌道要素、編目時間 | 真實尺寸、材質與故障原因 |
| 軌道反推 | 共同事件時間、相對速度分布、可能來源 | 把模型最佳解當現場錄影 |
| 原因判定 | 需結合遙測、光變、軌道變化與碎片分布 | 只看「DEB」便斷言電池爆炸或遭攻擊 |

「至少43個已編目碎片」也不等於「總共碎成43塊」。偵測是感測器在某次觀測看見回波；編目還要把多次觀測關聯成同一物體，估計可持續更新的軌道。更小、雷達截面更弱或姿態不規則的碎片可能沒有獨立編號。

## 二、怎麼替衛星做「太空驗屍」

軌道碎裂會把母體的一部分速度增量分給碎片。研究者可把碎片軌道向前、向後傳播，尋找軌跡最集中時刻，再比較母體事前事後軌道、姿態光變與機動紀錄。這是統計鑑識，不是完美倒帶；兩行軌道根數（TLE）本身是配合特定傳播模型的近似資料，不含物體形狀、質量和事故原因。

判讀時可先問：

1. 母體是否仍被獨立追蹤，軌道有沒有明顯跳變？
2. 碎片的速度散布大不大，是否像高能量災難性解體？
3. 是否有已知物體在候選時間接近？碰撞幾何是否成立？
4. 衛星是否仍機動或維持姿態？光變是否顯示翻滾？
5. 碎片數是否隨觀測增加，分類是否被後續資料修正？

低能量脫落、壓力容器或電池事故、高速碰撞都可能留下碎片，但分布與母體狀態不同。沒有營運方遙測時，原因應維持「未確認」，而不是選最戲劇化的版本。

## 三、為什麼約960公里的逆行軌道值得注意

低地球軌道不是「離地面很近」的單一薄殼，而是延伸到約2,000公里。四百公里附近仍有顯著大氣阻力；八百到一千公里的自然清除慢很多，碎片可能長期穿越繁忙高度帶。逆行物體與多數順行衛星相遇時，幾何上可能有更高相對速度，但個別碰撞風險仍要看兩條軌道是否在同一時間交會，不能只憑傾角下結論。

最棘手的不是最大或最小碎片：大型物體較容易追蹤並規劃閃避；毫米級物體可由局部防護吸收；介於兩者之間的碎片可能已足以摧毀衛星，卻未必能被穩定編目。

## 四、現實版防護罩是分層系統

| 防線 | 主要功能 | 做不到的事 |
|---|---|---|
| 監測與編目 | 找到物體、更新軌道與不確定度 | 看見所有毫米碎片 |
| 近接評估 | 估算交會幾何、碰撞機率與後果 | 把預報變成確定命中 |
| 避碰機動 | 在仍有控制與推進劑時改變軌道 | 無成本地閃避每一個警報 |
| Whipple盾 | 讓小型高速碎片先破碎、熔融或汽化並分散載荷 | 擋住任意大小的衛星或火箭級殘骸 |
| 分艙與冗餘 | 限制穿孔、斷線或失壓的後果 | 讓災難性撞擊消失 |

碰撞機率不是「會撞／不會撞」的神諭，而是相對位置、速度、物體有效半徑與協方差共同形成的決策量。太早機動會浪費燃料並改變後續預報；太晚又可能失去選項，因此還要比較任務代價與碰撞後可能生成的碎片。

## 五、最有效的碎片技術常發生在事故以前

國際減緩準則把鈍化定義為消除任務結束後的儲存能量，例如排空或燃盡剩餘推進劑、釋放壓力與放電電池。這比等爆炸後再追幾千塊碎片有效得多。

完整生命週期還包括：

- 在設計階段保留可靠的任務終止與離軌能力；
- LEO任務縮短離軌等待時間，GEO任務移往合適的墓地軌道；
- 可控再入把落點放在遠離人口處；設計可燒毀性降低倖存碎片；
- 提供可被拖船抓取的介面，但不把主動清除當成可以繼續製造垃圾的免罪券；
- 持續分享軌道、機動與不確定度資料，避免不同營運者互相猜測。

ESA 2026年報告強調，碎片環境即使停止新增發射仍可能因碰撞繼續惡化；但「凱斯勒症候群」不是某天突然出現一面垃圾牆，而是特定軌道帶在多年到數十年以上逐漸累積的碰撞回饋。

## 六、現實科技不是一條直線

遊戲科技樹適合教依賴關係，卻容易讓人以為A研究完就必然解鎖B。真實科技更像有回饋的網路：材料、製造、能源、感測、控制、軟體、測試設施、法規、供應鏈與任務需求互相拉扯。某個原理被證明，不代表可在指定質量、功率、溫度、成本與可靠度下工作。

NASA的技術成熟度（TRL）從基礎原理到實際任務驗證分成九級。TRL只回答「成熟到哪裡」，不自動回答它是否便宜、可量產、可維修、合法或適合這個任務。科技樹至少應同時顯示：

| 維度 | 核心問題 |
|---|---|
| 成熟度 | 是論文、實驗件、原型、環境驗證，還是任務證明？ |
| 系統限制 | 質量、體積、功率、冷卻、成本與可靠度是否可接受？ |
| 依賴 | 需要哪些材料、製程、感測器、軟體與測試設施？ |
| 補給 | 彈藥、推進劑、備件與人員如何補充？ |
| 失效 | 它會如何降級、被繞過或造成共同原因失效？ |
| 證據 | 是實測、可驗證理論、概念研究，還是作品規則？ |

## 七、三種攻擊與三種防禦要按物理分類

| 系統 | 定義 | 真正瓶頸 |
|---|---|---|
| 實彈 | 發射器先把速度交給彈體；離膛後主要靠慣性 | 彈藥、後座、命中提前量與高速碰撞防護 |
| 導彈／無人機 | 離架後仍能感測、導引並產生速度改變 | 成本、彈艙、資料鏈、電子戰與點防禦 |
| 光束／粒子束 | 不以宏觀彈體飛抵目標 | 光束品質、指向追蹤、功率、作用時間與廢熱 |
| 裝甲 | 用材料、幾何和間隔層承受或分散載荷 | 質量與只保護被覆區域 |
| 主動場／護盾近親 | 磁場、電漿或主動介質處理特定粒子與輻射 | 不能一種場同時擋中性巨物、雷射與所有輻射 |
| 點防禦 | 偵測、分類、分配武器、追蹤、攔截與確認 | 通道數、反應時間、彈藥、視線與飽和攻擊 |

「雷射剋裝甲、實彈剋護盾」只能當遊戲規則。現實反制是軟的：反射塗層會被污染或燒蝕，裝甲會增加質量，點防禦能被假目標與同時來襲數量壓垮，導彈也能以更好的感測、分散接近或電子防護反制。

## 八、武器的四本帳

任何星艦武器至少有四本帳：

1. **能量**：一次射擊總共需要多少焦耳。
2. **功率**：要在多短時間輸出；同樣能量壓到更短脈衝，需要更高峰值功率。
3. **熱**：輸入能量中沒有送到目標的部分去哪裡；真空中最後多半要靠輻射器排出。
4. **庫存**：砲彈、攔截彈、無人機、冷卻劑、元件壽命與維修工時還剩多少。

所以「母艦沒受傷」不等於仍有戰力；它可能已用完攔截彈、無人機或散熱裕度。相反地，厚重材料文明可能船體傷痕累累，卻仍保有可持續的彈藥與修復能力。

## 九、三種文明不是屬性相剋，而是三種失敗方式

| 文明路線 | 強項 | 真正血條 | 典型失敗 |
|---|---|---|---|
| 材料／動能 | 裝甲、結構、量產與長時間正面戰 | 船體、機動與維修產能 | 太重、太慢，被放風箏或避戰 |
| 能量／場 | 光束、感測、電力整合與主動防禦 | 電網、電容、散熱與光學品質 | 過熱、失電、被繞過防禦後船體脆弱 |
| 自律／導引 | 遠程偵察、導彈、無人機與分散協同 | 可消耗平台庫存、資料鏈與補充速度 | 彈艙見底、鏈路受干擾、被迫近距離決戰 |

這三條不是宇宙必然文明分類，而是設計世界觀的系統工程模板。真正成熟的文明會混合路線；專精的代價不是固定的`+25%`，而是供應鏈、能源、熱、機動、感測和指揮架構共同造成的戰爭節奏。

## 十、越過現實邊界時要掛牌

建議所有科技卡採四級標記：

- **已觀測／已運用**：軌道追蹤、Whipple盾、雷射測距、導彈導引。
- **原型／研究中**：高能雷射、光學相位陣列、主動清除、部分電漿或磁場防護。
- **理論可談但未工程化**：大規模反物質推進、宏觀曲率操控等。
- **作品規則**：剛性透明護盾、相位炮、因果武器、存在抹除。

最後一級並不是「不准好玩」，而是不能假裝已有實驗數據。好的科幻科技樹會明確說出借用了哪個現實概念、跨過了哪道尚未解決的障礙，以及世界觀額外允許了什麼規則。
