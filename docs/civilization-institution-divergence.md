# 文明制度分歧：科技樹之外的治理樹

整理日期：2026-09-14。這一冊追問同一套科技落入不同制度後，為什麼會長成不同文明。它不是替某種政體排名，而是拆解權力來源、資訊流、問責、退出與代際風險。

## 五個固定檢查角度

| 角度 | 要問的事 |
|---|---|
| 授權 | 誰有權作決定，權力從哪裡來？ |
| 資訊 | 誰提供資料，錯誤如何被發現？ |
| 問責 | 決策者失敗時能否被撤換、申訴或審查？ |
| 分配 | 成本、利益、聲音與風險落在誰身上？ |
| 退出 | 個人、聚落或星球能否拒絕、離開或另組制度？ |

## 制度不是單選題

- 直接民主提高直接參與，但大規模、專業資訊與決策疲勞會限制適用範圍。
- 代議民主把時間交給代表，代價是委託代理問題、金錢與資訊權力。
- 公民議會用隨機抽選和充分審議補充選舉，不能取代執行與正式問責。
- 技術官僚能改善技術判斷，卻不能把價值衝突偽裝成只有一個正確答案。
- 聯邦把共享治理與地方自治結合；權限、財政與緊急狀態的邊界仍需明定。
- 分權、兩院制、司法審查與獨立監督會降低速度，目的正是讓重大錯誤更難一次貫穿全系統。

## 數位與星際制度

- 演算法可協助整理提案與模擬後果，不應秘密決定權利、刑罰或公民資格。
- 液態民主讓人直接投票或按議題委託，但介面控制、代理集中與身分安全可能產生新權力中心。
- 星際通訊延遲使即時中央統治不切實際；地方自治、預先授權與事後稽核比幻想零延遲命令更可信。
- 世代船同時是城市、工作場所與不可輕易退出的生態系；生命維持控制權不能等同一般公司管理權。
- 人工心智、複製人與群體心智的公民資格，應看感受、利益與自主能力，不能只看出生材料。

## 經濟制度分歧

- 平台與企業治理會受所有權、資料、網路效應與轉換成本影響；使用者按一下同意不代表真正具備議價能力。
- 工作者合作社讓成員同時成為工作者與所有者，仍需處理專業管理、資本、成員衝突與非成員勞工。
- 聲望可補充貨幣無法表達的信任，卻容易形成 popularity contest、報復評分與永久污名。
- 基本物資自動化不會讓土地、照護、注意力與政治權力消失，後稀缺文明仍需要分配制度。

## 適合導引學習的追問

1. 如果制度做對了，誰得到好處？
2. 如果制度判斷錯誤，誰先受傷？
3. 不同意的人有沒有申訴與退出路徑？
4. 危機時暫停的權利，何時以及由誰恢復？
5. 如果自己出生在最弱勢的位置，還會接受這套制度嗎？
