報告者：秋芸羊。一人報告 30 分鐘。對應本目錄新版 `SPEAKER_30MIN.md` 的 P01–P23。

這份文件是 23 頁擴充彩排稿的版面規格。正式主簡報另已重製為 11 頁 v10，放在 `deliverables/永恆北極星_全視覺導引學習版_v10.pptx`；兩者不要混稱為同一份頁序。

## 先固定內容

講者的話以 SPEAKER_30MIN.md 為準，來源、數量和測試界線見 REPORT.md。保留目前頁序，尤其是：P04 改口 Gemma、P07 兩次沒答出來、P08 的 1001、P16 集中實機展示。

不要再把「因為喜歡天文」「這次有免費額度」「測了覺得不滿意」改成教育使命或品牌策略。不需要每頁一句金句。小朋友是否喜歡、之後是否繼續維護，照講者原意保留不確定。

講稿放備忘稿。投影片只放這一頁需要看的內容，不照搬全部句子，也不要替講者安排天才少女、熱血主持人或企業提案人格。

## Impeccable 的用法與界線

參考使用者指定的 `pbakaus/impeccable` 官方 README 和 `.agents/skills/impeccable/SKILL.md`。本次讀到 skill 版本 4.3.1，blob 為 `2f12a53b1e5eaa38fd69625926340704a4ced54b`。[I1][I2]

官方定位主要是前端介面的設計指引；這裡借用視覺層級、精簡、排版、版面節奏和有限次檢查的原則，不把它當成已確認能原生讀寫 PPTX 的外掛。本次沒有安裝、執行 CLI 或加入 hooks。

已有 skill 的製作者可以參考 `critique`、`distill`、`typeset`、`layout`、`polish`。PPT 本身仍要用合適的簡報工具製作；不為了用這個 skill，另外架網站、改 Bot 或重構專案。

## 畫面方向

這是課堂報告，閱讀與展示優先。封面可以留天文氣氛，內頁不要每頁疊星空、光暈和半透明卡片。也不要把它做成網站首頁，加產品口號和行動按鈕。

繁體中文使用清楚可投影的字體。起始設計值可採主標 32–44 pt、正文 24–30 pt、來源 16–18 pt，再按實際投影調整。擠不下先減字或拆備用頁，不一路縮成小字。這是本簡報的設計建議，不是 Impeccable 官方 PPT 規範。

橘色與白色留給草地案例等有意義的位置。顏色不能是唯一辨識標籤。需要流程圖就畫流程圖，需要實機證據就放真實畫面，不把所有東西都排成三欄卡片。

所有代表機器人實際發言的對話框統一使用淺藍色；使用者訊息使用另一種中性色或淡綠色，並保留「守門人／使用者」文字標籤，避免只靠顏色判讀。系統架構框、資料卡與標題不是對話，不套用這條規則。

## 素材與驗收

P07 是講者回憶，沒有原始紀錄就不仿造截圖。P16 使用同版本實際錄製或截取的 LINE 畫面；沒有素材時，清楚標示意並使用講稿的替代旁白。AI 生成畫面不能當作跑過測試的證據。

科幻景觀和機制插畫標示意。天文觀測影像則保留原來源及必要處理方式說明。金鑰、私人對話、完整使用者識別都不要投出來。

先檢查現有 PPTX，再排 P01、P07、P17 三種版型，確定圖片、故事和技術頁的文字層級一致，才做其餘頁。完成後一次渲染全份，集中檢查裁切、溢出、遮擋、字級、頁序、引用與備忘稿，再修正並確認；不要用無限裝飾微調消耗時間。有實質缺陷仍須修正或明列，不能掩蓋。

最後交付可編輯 PPTX、PDF 預覽與更新說明。逐字稿放備忘稿，不把整頁圖片稱作可編輯投影片，也不只有規格文件就宣稱重製完成。
