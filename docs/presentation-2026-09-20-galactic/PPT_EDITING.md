## 設計原則

參考 Impeccable 的「精簡、層級、排版、有限檢查」精神，但這不是 Impeccable 官方 PPT 支援聲明。

這版不追求華麗：

- 深色底、少量金色重點。
- 每頁只放上台需要看的短句。
- 詳細講法放備忘稿與 Markdown 講稿。
- 不把示意圖當實機畫面。
- 沒有原始聊天截圖，就標成回憶重述。
- 科學計算明確標假設，不當成實驗結果。

## 投影片與講稿分工

投影片負責讓觀眾跟上。

講稿負責保留完整說法。

所以 PPT 上不要放整段句子，尤其不要把：

> 因為我這次用的是免費額度。

改成：

> 基於資源配置與永續營運考量。

那樣 AI 味會直接復活。

## Demo 備援

Demo 頁只跑事前測過的操作：

1. 問「啟明星和長庚星為什麼是同一顆？」
2. 追問「那為什麼有時候早上看到，有時候晚上看到？」
3. 進入學習，選已測過路線，回答一道理解題
4. 退出後輸入「挑戰」，展示固定題與解說

若模型 API 暫時不能用，展示固定題庫與學習流程。

若 LINE 或伺服器不能用，播放同版本錄影。

沒有錄影就用流程圖說明，不能把示意說成實測。

## 重點邊界

- `1001`：早期彩蛋，不是現行上限。
- `1534`：1234 張知識卡 + 300 道固定試煉題。
- `Gemma 免費`：描述這次方案與額度，不承諾永久免費。
- `哈雷彗星／卡爾薩根`：開發測試回憶，不是模型能力評測。
- `258 kcal`：教學假設下的估算，不是人體實驗。
- `十光年`：跨恆星系通訊示例，不要寫成跨星系。
