## PPT 風格

主簡報已借用 Impeccable 的排版、精簡、層級與有限次檢查原則重製為 v10；PPTX 本身仍由專用簡報工具產生，不把 Impeccable 當成原生 PPTX 編輯器。

不要每頁三張卡片、每個標題一顆圓角圖示。實機畫面就放實機畫面，系統架構就放流程圖。尤其不要把「因為這次有免費額度」改成「基於成本最佳化與永續營運」。

逐頁做法見 PPT_EDITING.md。v10 中凡是機器人實際說出的話一律使用淺藍色對話框，使用者訊息則採不同顏色；一般系統節點不因為含有「回答」兩字就套成對話泡泡。
