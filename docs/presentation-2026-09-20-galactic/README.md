## 為什麼不是 1001 了？

1001 是早期彩蛋，因為《一千零一夜》。就這樣。

現在資料契約是：

**1234 張知識卡 + 300 道固定試煉題 = 1534 個內容單元**

1001 不再是現行上限，也不是一千零一個資料庫。
