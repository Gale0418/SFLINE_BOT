# 科幻科技可行性圖鑑：從光劍到反物質星艦

整理日期：2026-09-14。這份圖鑑不只問「理論有沒有出現過」，還追問作品版本是否需要無限能源、違反守恆律、忽略廢熱，或把微米級實驗直接放大成星艦級工程。

## 四級可行性標尺

| 等級 | 定義 | 例子 |
|---|---|---|
| A：已有原型 | 核心功能已在實驗室、醫療、工業或太空中出現 | 外骨骼、VR／AR、手持多感測器、人形太空機器人 |
| B：物理允許 | 基本機制可信，但尺度、能源或可靠度不足 | 旋轉人工重力、微粒牽引光束、雷射定向能 |
| C：局部像 | 只在特定波長、材料或小尺度重現作品的一角 | 隱形超材料、3D食物列印、組織生物列印 |
| D：缺乏機制 | 沒有可驗證路徑，或要求改寫已知物理 | 重力甲板、慣性阻尼器、作品式能量護盾、無反作用力推進 |

同一項科技可以跨級：例如「雷射推動微粒」已被研究，但「用光束拖走企業號」仍是科幻。

## 主人最喜歡的光劍，卡在哪裡？

```text
作品需求
發光刀刃約 1 m 長
＋ 刀刃末端會停止
＋ 能互相格擋
＋ 能快速切金屬
＋ 握柄可收納全部能源與磁場
＋ 使用者不會先被熱死
```

雷射不是好答案：它會繼續傳播，兩束普通光也會互相穿過。電漿可以發光並切割，但磁約束裝置通常需要包圍電漿的線圈與真空結構；開放、細長、可揮舞的電漿柱會膨脹、散熱並傷害附近使用者。

因此，可以做出「外觀看起來像光劍」或「能切割的手持電漿炬」，卻無法同時滿足作品全部條件。最難補上的不是顏色，而是有限長度、互相碰撞、便攜能源與熱管理。

## 《星際大戰》科技

| 科技 | 現實近親 | 關鍵缺口 | 等級 |
|---|---|---|---|
| 光劍 | 雷射、電漿炬、磁約束 | 光束不會定長；電漿難以開放約束；廢熱 | D |
| 爆能槍 | 雷射、微波、粒子束 | 電源、散熱、大氣傳播；可見慢速光彈不合理 | B／D |
| 超空間 | 曲速、蟲洞等數學模型 | 沒有已知可進入的超空間或可控FTL | D |
| 機器人夥伴 | 人形機器人、AI、遙操作 | 通用常識、可靠自治、電力、維修與意識問題 | A／C |
| 死星 | 定向能與天體撞擊 | 地球束縛能約 `2.2×10³² J`，另有聚焦與廢熱 | D |

「摧毀文明」和「炸散行星」不是同一能量級。死星效果要求碎片克服整顆行星的自引力，最低能量約等於太陽六天的總輻射輸出；武器本身還不可能百分之百轉換。

## 《星際爭霸戰》科技

| 科技 | 現實近親 | 關鍵缺口 | 等級 |
|---|---|---|---|
| 相位槍 | 雷射與微波定向能 | 萬用擊暈／分解模式、生物選擇性與熱管理 | B／D |
| 傳送器 | 量子傳態、掃描、製造 | 量子態不是人體物質；資料量、破壞與身分問題 | D |
| 複製機 | 3D列印、食物列印、自動化合成 | 必須先有原料；原子級組裝、能量與速度 | C |
| 全像甲板 | VR／AR、空間聲音、觸覺回饋 | 裸眼多人影像、任意實體觸感、空間與安全 | A／C |
| 萬用翻譯器 | 語音辨識與神經機器翻譯 | 完全陌生語言沒有對照語境，無法唯一解碼 | A／C |
| 三錄儀 | 手持超音波、光譜、化學與生命徵象感測 | 一掃即診斷的敏感度、特異度與臨床驗證 | A／C |
| 隱形裝置 | 雷達匿蹤、主動迷彩、超材料 | 全角度、全波段、熱訊號與內外同時可見 | C |
| 反物質核心 | 粒子加速器、電磁陷阱 | 生產效率、巨量儲存、伽馬射線與事故 | C |

量子傳態傳送的是量子態資訊，而且仍需要傳統通訊；它不是把人分解後瞬間搬走。複製機比較合理的硬科幻版本，是帶有原料匣、化學合成與3D列印頭的高度自動化工廠。

## 星艦常見的三個「劇情黏著劑」

### 重力甲板

現有物理能以旋轉或整船持續加速模擬重力。若每層地板都能向下產生1g、又不影響隔壁房間，便需要尚未知的局部重力控制。比較硬科幻的寫法是旋轉艙、纜索雙艙或推力重力。

### 慣性阻尼器

星艦若瞬間急轉，船殼和人體都必須承受加速度。座椅、液體承托、壓力衣和主動懸吊可以降低局部傷害，不能讓慣性消失。比較合理的寫法是降低加速度、提前規劃航線，或承認旅程需要更久。

### 能量護盾

磁場可以偏轉帶電粒子，卻擋不住所有中性物、雷射與高速隕石。現實防護要分層：Whipple實體盾處理微流星體，材料與磁場分別處理不同輻射，機動與偵測避免大型撞擊。

## 逐漸靠近現實的科技

- **人形機器人：**NASA Robonaut已在太空工作，但仍是特定任務系統，不是具有完整人格與萬能常識的仿生人。
- **動力外骨骼：**可協助復健、運動與局部增力；真正裝甲還受電池、散熱、重量和人體關節負荷限制。
- **三錄儀：**手機、穿戴裝置、手持超音波與化學感測正在融合，但醫療上不能跳過校準、假陽性與醫師判斷。
- **醫療再生：**組織工程和生物列印能製作模型或較簡單組織；完整器官還需要血管、神經、免疫整合和長期成熟。
- **全像甲板：**視覺與聲音進步很快，最難的是讓多人摸到同一個不存在的物體，並在有限房間內安全奔跑。
- **萬用翻譯：**已知人類語言可以近即時翻譯；第一次接觸的外星語仍需要共享情境、重複觀測與驗證。

## 微小尺度最容易被科幻偷偷放大

| 新聞標題可能寫成 | 實際成果 | 不能直接推出 |
|---|---|---|
| 科學家發明牽引光束 | 用光控制微粒或收集塵埃的概念 | 拖曳太空船 |
| 隱形斗篷成真 | 在特定波長、方向與小尺寸降低散射 | 人在日光下全角度消失 |
| 奈米機器人治病 | 奈米載體或受外場驅動微結構 | 自主修補每個細胞 |
| 記憶晶片成功 | 神經訊號解碼或刺激特定記憶工作 | 下載完整人格與回憶 |
| 反物質已被儲存 | 少量粒子在電磁陷阱中維持 | 星艦燃料槽裝滿公斤級反物質 |

## 無反作用力不等於無推進劑

太陽帆不帶燃料，卻和光子交換動量；電帆和太陽風粒子交換動量；磁帆與外部電漿或磁場作用。真正封閉、完全不與外界交換動量的裝置若持續自行加速，會違反整體動量守恆。

```text
可信推進：飛船向前動量 ＋ 噴流／光子／外界向後動量 = 原本總動量
反應less宣稱：只有飛船得到淨動量，卻找不到另一半 → 必須先懷疑量測誤差
```

## 導引式學習建議

1. 問：「你最想偷走哪一項科幻科技？」
2. 讓使用者選作品：星際大戰、星際爭霸戰、鋼鐵人或其他。
3. 先講作品規則，再找現實近親。
4. 挑戰題依序檢查能源、動量、廢熱、尺度與人體耐受。
5. 最終任務：把一項D級科技改寫成A或B級硬科幻版本。

例如將光劍改為「外骨骼支撐的短柄高功率電漿切割器，使用時必須配戴隔熱裝甲且不能互相格擋」，帥度稍降，但至少使用者不會第一秒就熟成 (＝_＝;)。
