# 科幻行星類型大全：從沙漠世界到巧克力星球

整理日期：2026-09-14。科幻作品常把整顆行星濃縮成一種強烈環境，方便觀眾一眼認出舞台；現實行星通常會有緯度、海拔、季節、海陸與氣象差異，不會真的只有單一生態區。

## 三種科學身分

- **現實已有對應**：氣態巨星、冰巨行星、熔岩世界、岩石行星、流浪行星等確實存在或已有強力候選。
- **物理上合理但尚未確認細節**：全球海洋、沙漠、雪球、碳世界、眼球行星、鐵世界。
- **主要是科幻舞台**：全球森林、城市行星、活體行星、中空世界、甜點行星；局部元素合理，整顆世界則需要極端條件或人工建造。

## 常見類型速查

| 類型 | 典型景觀與故事功能 | 現實科學判斷 |
|---|---|---|
| 沙漠行星 | 沙海、岩漠、缺水聚落、香料或水資源衝突；如塔圖因、阿拉基斯 | 乾燥岩質世界很合理，但仍可能有極冠、地下水、鹽原與季節，未必整顆都是沙丘 |
| 海洋行星 | 全球深海、浮城、海底文明、永不停歇的風暴；如卡米諾 | 水世界是正式假說；深海底部可能形成高壓冰，切斷海水與岩石的營養交換 |
| 熔岩行星 | 岩漿海、火山河、灼熱礦場；如穆斯塔法 | 已知超短週期岩質系外行星可能擁有熔岩海，這是最接近現實的科幻地貌之一 |
| 冰封／雪球行星 | 全球冰原、冰下海、熱泉聚落；如霍斯 | 地球曾歷經近全球冰封期；冰下液態水可由地熱、潮汐或鹽分維持 |
| 森林／叢林行星 | 巨樹、發光森林、完整生物網；科幻常把衛星也稱作森林世界 | 有生命才可能形成；全球單一森林會受海洋、沙漠、高山、火災、土壤與氣候帶打破 |
| 城市行星／Ecumenopolis | 都市覆蓋全球，多層交通與地下工業；如科洛桑 | 工程上遠超現代能力；廢熱、食物、水、氧、材料與垃圾循環比建築高度更難 |
| 氣態巨星／雲海世界 | 漂浮城、空中生物、無底風暴 | 巨行星真實存在且沒有普通地面；適居雲層仍需解決浮力、營養、能源與垂直對流 |
| 冰巨行星 | 青藍雲層、甲烷風暴、深層高壓流體 | 天王星與海王星是真實例子；「冰」指形成物質，不代表能站在冰地板上 |
| 眼球行星 | 永晝面灼熱、永夜面冰封，兩者間形成環狀暮光帶 | 潮汐鎖定行星的合理氣候候選；濃厚大氣與海洋環流可能把熱輸往夜面，避免極端眼球外觀 |
| 流浪行星 | 不繞恆星，在星際黑暗中漂流；地熱或厚大氣下藏著生命 | 已有孤立行星質量天體候選；表面極寒，但厚冰下海洋或氫氣溫室是理論可能 |
| 碳／鑽石行星 | 黑色石墨平原、碳化物地殼、深層鑽石 | 高碳低氧組成可能產生不同礦物；「整顆純鑽石」是媒體化簡，不等於已證實內部結構 |
| 鐵／金屬行星 | 巨型鐵核裸露、磁場與熔融金屬地景 | 富鐵岩質行星合理，可能由巨大撞擊剝去地函；金屬地表仍可能覆有岩石、氧化物或岩漿 |
| 毒氣／溫室行星 | 酸雨、腐蝕雲、窒息大氣、失控溫室 | 金星就是警告；但「酸雨落到地面」須看液滴是否會在高溫下降途中蒸發 |
| 玻璃雨／極端風暴行星 | 超音速風、側向玻璃雨、永恆颶風 | 熱木星光譜與氣候模型容許矽酸鹽雲、熔滴與高速風，但遠端資料常不足以重建電影式天氣 |
| 雙日／多日行星 | 天空有兩顆太陽、雙重日落、複雜季節 | 環聯星行星已被發現；軌道可以穩定，但氣候與照明週期比單星更複雜 |
| 人造／中空世界 | 戴森群、環世界、行星尺度機器、內表面城市 | 沒有觀測證據；中空天然行星無法承受自重，較合理的是人工薄殼或旋轉棲地，而非挖空普通行星 |
| 活體行星 | 整顆星球是一個生物、神經網或共同意識 | 全球生物圈能改變大氣是真的；但單一行星級個體與統一意識沒有證據，主要屬科幻 |
| 巧克力行星 | 黑巧岩原、可可脂海、糖晶雪、發酵沼澤、暮光帶甜點城 | 天然行星不會在高溫形成史中保留全球食品級巧克力；最合理版本是高等文明建造的低溫主題棲地 |

## 進階變體：把兩種世界疊在一起

比起整顆星只有一種材質，更可信的科幻世界可以混合兩到三個旋鈕：

- **潮汐鎖定沙漠眼球**：日下點是玻璃化荒漠，暮光環有河谷城市，夜面儲存冰。
- **冰封海洋世界**：表面像雪球，冰下卻有潮汐熱泉與黑暗生態。
- **熔岩鐵世界**：失去地函的富鐵行星靠近恆星，夜面凝成金屬殼，日面翻湧岩漿。
- **森林月球**：厚大氣衛星繞著巨行星，夜晚整片天空被行星與行星環佔據。
- **流浪海洋世界**：沒有日出，以地熱維持冰下海；生物靠化學能而非光合作用。
- **城市—海洋混合世界**：都市集中於浮動群島，保留大部分海洋作散熱、食物與水循環。

## 巧克力行星「可食用版」設定

名稱：**可可亞－β（Cocoa β）**

- 它不是天然形成，而是高等文明以小行星資源建造的旋轉式甜點棲地。
- 黑色山脈是耐熱的高可可固形物複合材料；真正可食部分只存在於受控農業與食品區。
- 可可脂會因晶型和溫度改變口感，城市必須維持低溫乾燥；靠近燈源的「融化季」會成為年度災害。
- 白巧克力極冠儲存脂肪與糖，糖晶雪由食品工廠排出的水氣和糖氣膠凝結而成。
- 發酵沼澤培養酵母與可可微生物群，卻也是最危險的二氧化碳低窪區。
- 原生居民不是巧克力人，而是穿冷卻服的維修文明；否則第一個晴天就集體融化，太蠢了。
