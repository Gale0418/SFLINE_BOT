# Guardrails

- 預設不讀取、顯示、記錄或提交任何秘密值。若使用者明確授權的操作確實需要秘密，只讀取指定檔案／欄位／行，值僅供該次操作使用；不得輸出、寫入日誌、檢查紀錄或提交原始值。
- `.env` 原則上不覆寫，來源 TXT 不自動刪除。明確授權的例外只限 LB-007 已核准的 `AI_PROVIDER=openai`、`OPENAI_MODEL=gpt-6-luna` 設定更新；不擴張成全面重寫 `.env` 的許可。
- NAS SSH 驗證所需的 KEY 檔只讀取該操作指定的單一行，不列印檔案內容或秘密值。
- 不在簽章驗證前解析 LINE webhook body。
- 沒有實際通過證據不得將任務標為 Done；候選 parity／POSIX 通過不等於正式部署完成。
- 不把分類 Accuracy 描述成自然語言回答的事實正確率，也不把舊模型結果描述為 GPT-6 Luna 成績。
- 不把有限回歸或審查結果寫成未來不會再有 bug 的保證。
