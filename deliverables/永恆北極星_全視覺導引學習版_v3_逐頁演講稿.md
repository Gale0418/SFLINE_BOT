# 永恆北極星：逐頁演講稿（全視覺導引學習版）

## 講者設定

講者採冷靜、推理清楚、能坦承證據不足的高材生風格。機器人本身維持沉穩而慈祥的睿智老人。

## 第 1 頁　封面（0:00–1:30）

各位評審老師、同學大家好，我是今天的報告者。我今天要介紹的專題是「永恆北極星」，這是一套在 LINE 通訊軟體中運作的科學問答與互動試煉系統。

我先很坦率地說明這項專題的初衷：出發點純粹來自於我對科學與宇宙的好奇。例如冥王星表面為何會有一顆醒目的愛心、木星深處是否真有導電的金屬氫，以及科幻電影裡的星際航行在現實物理中究竟有多少真實性。這些問題始終吸引著我，而我希望將這份探索的熱情，化為一個能夠在日常通訊軟體中真實互動的對話系統。

在角色的塑造上，系統平時是一位從容、睿智且充滿耐心的星空導引者；當使用者發起挑戰時，他則化身為守護知識的引路老人，以五道星門試煉檢驗理解。今天的報告不只展示機器人能回答問題，更會深入說明我們如何透過嚴謹的軟體架構，讓每一次互動都具備清晰的依據與結構。

本系統目前具備七十六張結構化知識卡、兩百二十題固定測驗題庫，以及八十段由核心知識精鍊重組的導引教材。整場簡報將依序涵蓋動機、專題目的與競品分析、架構技術、效能與缺口坦承、未來規劃，最後以完整的證據對應總結。

## 第 2 頁　1. 簡介（1:30–4:30）

我們的研究動機非常純粹：讓科學探索走入大眾最常使用的通訊介面。選擇 LINE 作為載體，是因為使用者不需要下載任何額外應用程式，就能以最自然的文字對話開始思考。

右邊這張圖是冥王星的概念插畫，並非探測器拍攝的原相。它表面最著名的特徵，就是這片被稱為「湯博區」的愛心形平原。對科學愛好者而言，這顆愛心不只是一個浪漫的地貌，更引發了一連串實質的科學探究：它由什麼冰層構成？為何板塊邊緣如此平整？當冥王星在 2006 年被重新分類為矮行星之後，我們該如何重新理解外太陽系的演化？

【停頓，讓觀眾觀看簡報畫面約十秒。】

同樣的好奇也經常出現在科幻作品中。例如《絕地救援》中在火星種植馬鈴薯的情節，引發我們思考：真實火星的過氯酸鹽土壤與極端大氣，究竟需要哪些生化條件才能維持作物生存？而《極限返航》的星際航行，則直接觸及了光速極限、相對論時間膨脹與星際推進的物理瓶頸。

「永恆北極星」的核心任務，就是回應並引導這類探索慾望。系統平時以溫和耐心的老人語調提供解釋，並附帶具體文獻來源；當使用者想檢驗自己的理解時，可隨時進入五題星門挑戰。即便使用者答錯，引路老人也會條理分明地解說原委，而非單純給出對錯標記。

在此我們也必須界定動機與實際應用的界線：個人興趣是打造系統的起點，而未來雖可延伸至課後自學或科教輔助，但本專題目前尚未進行正式的教學實驗前後測，因此我們絕不宣稱它已具備提升學業成績的實證效果。我們今天所報告的，是嚴謹的系統架構與扎實的工程驗證。

## 第 3 頁　2. 專題目的、相關產品（4:30–7:00）

本專題的目標，是打造一個在單一對話介面中，兼顧「自由發問」、「系統化導引學習」與「客觀驗證試煉」的三合一科學伴學系統。自由問答解答突發的好奇，導引學習建立脈絡，而固定試煉則提供可重現的理解檢核。

在規劃系統時，我們參考了兩款代表性產品的定位。第一款是 Google 的 NotebookLM，它高度強調「基於來源文件」進行理解與回答，這啟發了我們在問答設計中落實嚴格的來源依據與可追溯性，避免模型隨意幻覺。第二款是 Kahoot!，它透過單選題目與即時回饋，創造了高互動性的課堂測驗體驗，讓我們體會到清晰解析與即時反饋在學習過程中的重要性。

必須澄清的是，本頁面探討的是產品策略與功能定位的差異，我們並未在相同題庫下對三個產品進行評測排名，因此不會做出「本系統準確率超越商業成熟產品」的不實宣稱。

「永恆北極星」的專注點在於整合與輕量化：使用者無須切換工具，在 LINE 對話中就能自由探索太陽內部反應，或從「四座寶庫」選擇一條路徑依序推進。所有試煉題目皆具備預先審查的固定標準答案、詳盡解說與資料出處，絕不交由語言模型在前端隨機生成答案，確保評量的公正與穩定。

## 第 4 頁　3. 系統架構與技術：流程與路由（7:00–10:30）

請大家看畫面上這張完整的系統架構流程圖。這套架構的核心設計原則，是「明確狀態由程式掌握，開放語意由模型解析」。

當使用者在 LINE 發送訊息時，LINE 伺服器會將事件推送到我們的 Webhook 端點。伺服器首先執行嚴格的 LINE 簽章驗證，確認訊息來源合法，隨後進行假名化處理：我們絕不儲存使用者的真實 LINE ID 或聊天文字全文，僅使用加鹽的雜湊值作為內部狀態對應，確保個人隱私。

接著，訊息進入中央路由派發器。派發器根據當前使用者的對話狀態與意圖，分流至四個互不干擾的獨立管道：
第一是「自由問答路徑」：若使用者提出開放性科學疑問，系統會先比對本機高信心知識卡；若未命中，則調度外部大語言模型生成符合人設的回答。
第二是「五題星門試煉」：當使用者輸入「挑戰」或「考我」，系統切換為試煉守門人狀態，隨機抽選五道固定題目，逐題評分並記錄成績。
第三是「導引式學習路徑」：使用者說「學習」時進入，由四座寶庫循序引導。
第四是「系統指令路徑」：處理「說明」、「重設進度」等輔助管理功能。

在網路通訊層面，我們嚴格遵守 LINE Messaging API 的單次回覆限制，每個 Reply Token 僅使用一次，絕不做盲目的重複重試，以杜絕使用者端出現跳針或重覆訊息。整個流程確保各模組職責分明、資料流向完全可追蹤。

## 第 5 頁　3. 系統架構與技術：題庫與知識卡（10:30–14:00）

在內容資產的構建上，「永恆北極星」採用高度結構化的資料管理。目前系統包含七十六張結構化知識卡，以及兩百二十題經過專家審查的單選測驗題。

這些內容被嚴謹地劃分到「四座獨立寶庫」之中：
第一座是「星海寶庫」：涵蓋恆星演化、黑洞物理、系外行星與深空探測器歷程。
第二座是「地脈與生命寶庫」：探討地球板塊構造、地質年代、深海極限生物與外星生命宜居條件。
第三座是「萬象法則寶庫」：聚焦於相對論、量子力學基礎概念、熱力學定律與物質極端態。
第四座是「未來幻夢寶庫」：解析科幻電影與小說中的硬核物理，包含星艦曲速泡、戴森球假想以及戴森雲能量收集。

每一張知識卡都包含標準概念名詞、分層說明的重點內文，以及可追查的權威資料來源。而兩百二十道試煉題目，每題都具備確定的標準答案、干擾選項設計原則、詳細解析與關聯知識卡編號。

特別說明的是，這些題目全部以本機靜態資料集的形式儲存於伺服器端，由程式直接進行答案比對。這杜絕了模型隨機生成答案時可能出現的幻覺或評分不一致問題，使整套測驗系統具備完全的客觀性與可重現性。

## 第 6 頁　3. 系統架構與技術：自由問答與雙路徑（14:00–18:00）

自由問答是滿足使用者隨性探索的核心功能。為了在回答品質、反應速度與運算成本之間取得平衡，我們設計了雙路徑路由機制。

第一條是「本機高信心路徑」：當使用者的提問精準命中七十六張知識卡的核心實體或常見問題時，系統直接抽取知識庫內容，由伺服器在數十毫秒內組合回覆。這條路徑完全不發出外部 API 請求，既零成本又具備極高穩定度。

第二條是「雲端語言模型路徑」：當遇到跨領域、長句型或開放式提問時，系統會調用 Google Gemma 26B 模型（gemma-4-26b-a4b-it），透過系統提示詞約束模型的人格與邊界。引路老人的人格設定具備沉穩、謙遜與條理分明的特質：他用科學證據與生動比喻解惑，當遇到未解之謎時會坦誠說明「科學界目前尚無定論」，絕不不懂裝懂，更不編造虛假的數據。

此外，系統提示詞嚴格隔離科幻假設與真實科學，例如在討論曲速引擎時，會明確指出這是廣義相對論在阿庫別瑞度規下的數學推導，但目前缺乏負能量物質等工程實現基礎。透過這樣的雙軌設計，我們兼顧了問答的靈活性與科學敘述的嚴謹度。

## 第 7 頁　3. 系統架構與技術：導引式學習與星門試煉（18:00–22:00）

除了自由問答，許多學習者需要更具結構的循序路徑。為此，我們設計了「四座寶庫導引學習系統」與「五題星門試煉」。

導引系統將既有的知識資產重新精鍊為八十段短講教材。四條路線彼此完全獨立，每條路線規劃四個進階階段。每個階段包含五段概念講解與五道隨堂理解題，最後以綜合挑戰檢驗成效，學員須答對四題以上方能解鎖下一階段。必須誠實指出：這八十段教材是從七十六張知識卡與題庫體系中重新編排而來，並非憑空增加八十個全新主題，我們不誇大內容規模。

在資料架構方面，所有使用者的學習進度皆記錄在機器人伺服器端的 SQLite 資料庫中（data/private/learning.sqlite3）。使用者的手機端僅作為純粹的 LINE 介面展示文字與互動按鈕，絕對不會在用戶手機上儲存任何資料庫或執行 SQL 查詢。進度更新完全在伺服器端交易中處理，按鈕內嵌狀態版本防偽標記，有效防止重複點擊或跨階段作弊。

在語氣互動上，無論是在導引短講還是星門試煉中，引路老人始終保持耐心與鼓勵，提供充足的邏輯線索。如果使用者中途想回到自由提問或暫停，系統會完整保留其進度存檔，體現貼心而嚴謹的伴學體驗。

## 第 8 頁　4. 效能分析與缺口坦承（22:00–27:00）

身為一個負責任的工程專題，在展示功能的同時，我們更必須客觀呈現量化數據與當前的技術缺口。

首先在程式碼與自動化測試方面：目前專案已建立完整的本機單元與整合測試套件，總計一百七十二項測試全部順利通過（172 tests passed）。整個系統的總體測試覆蓋率達到 81.34%，其中核心的導引學習模組覆蓋率更達到約 95%。這證明了狀態機轉換、按鈕驗證、SQLite 交易與訊息路由邏輯在程式層面具備高度可靠性。

然而，我們必須非常坦誠地面對兩個重要缺口：
第一是「線上大語言模型的效能指標」：在九月八日進行的三十題線上模型基準評估中，由於當時外部 API 遭遇不可預期的服務中斷與網路逾時，該次評估未能取得完整的有效推論結果。本著求真精神，我們認為該次評估在統計上無效，因此我們既不會將其記為零分，也絕不拿少數幾次隨機成功的對話記錄來拼湊充數。目前系統的客觀 Accuracy、F1-score 以及 P95 延遲等數據，仍然維持「未經驗證」的坦白狀態。

第二是「實質學習成效」：我們高達 95% 的模組覆蓋率僅代表程式邏輯沒有瑕疵，絕不等於學生的學習成效提升了 95%。本專題尚未經過雙盲受試者實驗或前後測統計，我們絕不混淆「軟體測試覆蓋率」與「教育心理學成效」。未來必須在固定測試集與穩定網路環境下，重新建立可信的模型基準。

## 第 9 頁　5. 結論與未來工作（27:00–29:00）

總結今天的報告，「永恆北極星」成功將個人對天文物理的好奇心，轉化為一套兼具深度與穩定度的對話學習系統。我們整合了 LINE 自由問答、五星門試煉與四條獨立導引路線，具備七十六張知識卡、兩百二十題固定試煉以及八十段導引教材，並在伺服器端落實了安全的 SQLite 進度管理。

在這個專題的開發過程中，我最深刻的體會是：呼叫大語言模型僅僅是智慧應用的冰山一角。要打造一個能長期穩定互動的陪伴系統，背後更需要健壯的架構設計、狀態隔離、隱私假名化與客觀的資料回溯機制。

針對未來的發展藍圖，我們規劃了明確的四階段推進路徑：
「現在」，我們已具備完整的問答、試煉與四路導引架構；
「下一步」，我們將在穩定環境中重啟三十題線上模型基準評估，取得可靠的延遲與準確率數據，並錄製完整手機操作流程；
「再下一步」，我們將規劃真實使用者的質性訪談與教學前後測設計，驗證系統在教育場域的實質助益；
「最後」，在正式大規模部署階段，我們將導入跨主機共享儲存架構、定期異地備份機制與完整的隱私政策合規審查。

我們期許這套系統不只是一個展示品，而是一座能持續進化、禁得起檢驗的科學知識燈塔。
